# Help tutorial video

Place `help.mp4` in this folder (`assets/help/help.mp4`).

- Sent by the bot's **🎬 Help tutorial (video)** button (`menu:helpvideo`) via Telegram `sendVideo`.
- **Must be ≤ 50 MB** (Telegram Bot API send limit; the bot caps the read at 49 MB).
- Universally available to every user (main account and all Shadow Clones) — no owner gating.
- If the file is missing, the button answers with a graceful "not yet available" message instead of failing.
